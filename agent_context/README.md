# agent_context/

Context docs written **for an AI agent** (Claude Code) to load quickly when working
on this repo. Not user-facing tutorials — these are dense, accurate maps of how
subsystems fit together, with exact file paths, data flows, and gotchas.

**If you are an agent picking up a task: skim this README, then open the one doc
that matches your task.** Each doc front-loads the key facts and an "entry points"
section so you don't have to re-derive the architecture.

## Conventions for docs in this directory

- Lead with a **TL;DR / key facts** block — the 5 things an agent must not get wrong.
- Use **real, clickable file paths** (`path/to/file.py:line`), not prose descriptions.
- Include a **data-flow** section and an **entry points** section (where to start reading/running).
- Call out **gotchas** and **what does NOT exist yet** explicitly — misconceptions cost more than gaps.
- Keep it current: if you change a subsystem, update its doc in the same change.
