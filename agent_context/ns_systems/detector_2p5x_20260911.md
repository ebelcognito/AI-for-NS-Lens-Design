# Detector 2.5 × beam width — completed comparison

Repeated the 1.5× experiment with full detector heights 10/15 mm for 4/6 mm
input beams. Centre remains (120,-20) mm; fixed vertical reference [-55,50] mm;
n=1.60. A programmatic comparison of all 144 job configurations confirmed that
only detector_half_height changed, apart from output paths.

Same seeds 300–305, corners 3/4/5, four methods, 400 physical search calls per run,
population 10, and eight reserved 125-ray audits. Seeds are deliberately reused
for a paired detector-size comparison; this is not a new independent seed cohort.
The policy was not retuned. Historical CMA-ME is an adaptation of its archive-ranking
and restart behavior to common route niches, not an unchanged historical grid driver.

| Method | Successful runs | Passing 125-ray audits |
|---|---:|---:|
| naive | 0/36 | 0 |
| legacy_route | 0/36 | 0 |
| pilot | 0/36 | 0 |
| portfolio | 3/36 (8.3%) | 5 |

Portfolio versus each control: +8.3 percentage points, 95% seed-block bootstrap
interval [0,+19.4], one-sided seed sign p=0.25. **No statistically established gain.**
The earlier 1.5× run yielded 1/36 portfolio successes; this run yields 3/36.
This descriptive increase alone does not establish an effect of detector size.
Changing the detector changes ranks and CMA trajectories; the previously successful
seed did not rediscover its old design in this run.

All successes use the 6 mm input beam / 15 mm detector: triangle seeds 303 and 304,
and quadrilateral seed 304. Best audited throughput by successful run: 68.0%,
85.5%, 42.8%, respectively. All 144 budget logs checked, source hashes matched,
and all five stored audits replayed exactly. Each method used 388,800 search rays.

Two selected examples underwent 909-ray stress checks. The triangle passed with
the default branch cap. The quadrilateral hit the default 20,000-branch cap;
both examples passed with 200,000 and 400,000 branches and their results agreed
exactly across those two capacities. These are post-run diagnostics; no search or
primary audit result was replaced. Same tracer, not independent-engine verification.

## Reproduce

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 .venv/bin/python -m nslens.discovery.benchmark \
  --out runs/detector_2p5x_NEW --stage confirmation --candidate portfolio \
  --arms naive legacy_route pilot portfolio --seeds 300 301 302 303 304 305 \
  --corners 3 4 5 --briefs base wide --search-calls 400 --workers 6 \
  --detector-beam-ratio 2.5 --setup-y-bounds -55 50 \
  --detector-height-fraction 0.3333333333333333
```
